# 生成与质检故障复盘

单章目标保持 10,000 字，模型保持 Agnes 3.0 Flash，质量、字数与正式发布门不变。历史 526 次请求并非 526 次完整章节试验；其中包含规划、场景、扩写、润色、质检和修订请求。历史审稿没有保存完整原始评分，不能将全部失败归因于某一个缺陷。

## 已确认并修复的问题

| 问题 | 后果 | 修复 |
|---|---|---|
| 审稿缺失维度默认为零，信任模型给出的总分 | 协议错误被误判成文学低分，消耗正文修订预算 | 强制九项评分完整且范围合法；按原权重重算总分；仅允许一次格式修复，仍失败则保存技术诊断 |
| Reviewer 的设定和质量策略取自模块目录 | 隔离项目可能使用错误的圣经与质量上下文 | 显式传递项目根目录，缓存指纹包含实际圣经和规则 |
| 生成要求正常小说散文，同时禁止散文；过渡场景上限 800 字，与每场约 2,500 字冲突 | 正文偏短，后续反复扩写和低质量填充 | 统一正文、段落和场景字数契约，规划阶段获得实际字数预算 |
| 润色提示要求保留 90% 篇幅，程序却接受缩到 50% | 有效正文被缩短，再付费扩写 | 按原篇幅和场景字数下限验证候选；拒绝不合格缩稿 |
| 初始角色库的全部人物被作为当前可用演员 | 首次登场第 2 章的陈老根被安排在第 1 章，后续修文无法消除规划错误 | 按首次登场章节过滤生成上下文；未来角色仅提供禁止提前登场信息；规划校验同时检查 ID、姓名和状态变化；持久化仍保留完整角色库 |
| 下一章任务、后续场景的具体动作和结果未完整传递 | 后续事件被提前演完，形成重演和时间线错误 | 三次导演调用共享章节边界；写作约束覆盖具体事件、不可逆结果和未来演员 |
| 局部修订只有审稿建议，缺少冻结蓝图 | 错误建议可诱导新增残页、人物或能力 | 修订携带冻结场景、事件及伏笔；审稿建议不得改写既定事实 |
| 自动修复结束后可能留下比先前更差的稿件 | 质量退化、场景日志与正文不一致 | 保留已完整质检且通过硬门的最佳候选，恢复配套场景日志；恢复不代表发布 |
| 段落修订只要文字变化就继续占用全部修复轮次 | 全场节奏问题被当成三个局部段落问题反复处理 | 每章最多一次段落修订，复检仍失败则升级场景或全文修订，继续共用原预算 |
| 时间线记录固定写模块目录，缺少声明时默认数日 | 多项目数据串用，单夜章节也被记录为数日 | 按项目原子保存实际时间锚点、章内跨度；未声明的间隔明确记录未声明 |
| 导演 Craft 的 2,000 token 上限截断完整 JSON，精简重试又丢失顶层格式和时间反馈 | 返回零场景、重复规划，普通异常错误进入人工状态 | 输出上限调整为 3,000，保留顶层 scene_blueprints 格式和原时间反馈；所有导演失败统一进入一次有界重规划，仍失败则留诊断停止 |
| 预算异常的外层包装器使用空结果覆盖当前结果 | 最佳评分和修复历史在终止诊断中丢失 | 执行上下文保留当前结果，预算及包装异常均沿用该结果保存诊断；回归验证评分和历史实际落盘 |
| 时间线规则把“成年壮汉”等普通成人称谓当成主角年龄推进 | 真实试验中的配角描写触发无效整场重写 | 按当前命中位置区分成人称谓与年龄变化；“长成了成年男子”等真实推进仍阻断，并继续检查后续每个命中 |

普通配角现可用具体身份进入人物表，避免导演只列主角而写作器误以为是单人场。婴儿心理限制明确只针对主角，蓝图中的成人配角可进行符合设定的观察、判断与对话；未来主要角色仍不得化名提前登场。

质检记录现在保存原始分项、输入哈希、正文哈希和可核验的场景边界。有效低分不会为了获得更高分而原文重评。格式修复和内容修复均计入同一个章节预算，失败章保留稿件和诊断，不创建人工质检队列，不推进后章。
